EIGHT WEEKS TO A SOLID 5KM. Three runs a week: one easy, one that is
genuinely hard, and one long. That is the whole shape, and it is the shape
every distance plan in this library keeps — only the numbers change.

THE LADDER IS THE SATURDAY RUN, in kilometres, week by week: 3, 4, 4, 5, 5, 6,
5, 5. Week 7 steps DOWN on purpose. That is not a rest week you have earned
by being tired; it is where the adaptation from the six weeks before it
actually lands, and cutting it is the most common way a plan that was working
stops working.

FIVE KILOMETRES IS SHORT ENOUGH TO RUSH. The distance is not the hard part
for most people — the pace is, and the temptation is to run every run at the
same middling effort. Easy days must be easy enough that Thursday can be
hard. If all three runs feel the same, you are training one gear.

This is a MAIN plan: switch to it and it drives the week, with the Rest &
Recovery plan filling whatever it leaves empty. Want running alongside a
strength programme instead? Trail Base — Road to 15km is the parallel one,
built to sit next to a lifting week rather than replace it.

## Easy Run (tue)

Conversational the whole way. If you cannot talk, slow down — this run is
building the aerobic base every other run spends.

- Easy Run | 1 x 25-30 min easy

## Intervals (thu)

The hard one. Full warm-up first, and stop the session if anything sharp
appears — this is the run that finds a niggle.

- Interval Repeats | 5 x 3 min hard, 2 min jog
- Strides | 4 x 20s

## Long Run (sat)

Per the ladder above, slow. Walk the hills in the early weeks without any
guilt about it.

- Easy Run | 1 x per the ladder

## Recovery (sun)

- Recovery Walk | 1 x 20-30 min easy
